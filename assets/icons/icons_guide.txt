# Icons Guide — Local Booru
# Замени заглушки (чёрные квадраты 16x16) своими иконками.
#
# РЕКОМЕНДУЕМЫЕ РАЗМЕРЫ:
#   Сайдбар (nav):      20×20 + 40×40 (HiDPI)
#   Кнопки поста:       16×16 + 32×32
#   app_icon.ico:       16,24,32,48,64,128,256 px (все в одном ICO)
#
# Инструменты: https://icoconvert.com  или  Greenfish Icon Editor Pro
# ICO = несколько размеров в одном файле (Qt выберет нужный автоматически)
#
# ФАЙЛЫ:
#   parser.ico  —  Парсер (АПТ) — лупа/поиск
#   grabber.ico  —  Граббер — стрелка вниз/загрузка
#   gallery.ico  —  Галерея — сетка изображений
#   tags.ico  —  Теги — ярлык/тег
#   manga.ico  —  Манга — книга/страницы
#   games.ico  —  Игры — геймпад
#   dupes.ico  —  Дубликаты — два файла
#   nomatch.ico  —  Брак/NO_MATCH — вопрос или X
#   settings.ico  —  Настройки — шестерёнка
#   random.ico  —  Рандом — кубик/shuffle
#   post_prev.ico  —  Назад — стрелка влево
#   post_next.ico  —  Вперёд — стрелка вправо
#   favorite.ico  —  Избранное — сердечко
#   volume.ico  —  Громкость — динамик
#   fit_w.ico  —  По ширине — горизонт. стрелки
#   fit_h.ico  —  По высоте — вертик. стрелки
#   play.ico  —  Воспроизведение — треугольник
#   pause.ico  —  Пауза — две полосы
#   app_icon.ico  —  Иконка приложения (все размеры!)
#
# КАК ПОДКЛЮЧИТЬ:
# Код ищет assets/icons/<name>.ico автоматически.
# Если файл не найден — используется emoji (текущее поведение).
# HiDPI/4K: ico должен содержать размеры 16,32,48,64,128,256 px
