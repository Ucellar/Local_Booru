# Local Booru Companion 0.11.0 — Chrome / Edge / Brave / Chromium

## Установка

1. Запустите Local Booru v466 или новее.
2. Откройте `chrome://extensions/` или соответствующую страницу браузера.
3. Включите режим разработчика и загрузите папку `extensions/chrome_local_booru_companion` как распакованное расширение.
4. В Local Booru создайте одноразовый код сопряжения, затем введите его в popup.
5. Нажмите «Обновить профили сайтов». Для пользовательских сайтов отдельно выдайте optional permissions.

## Возможности

- **(0.11.0) «Скачать избранное» — лайки аккаунта в программу:** на странице аккаунта — его профиля или его
  избранного — на rule34.xxx, Gelbooru, Danbooru, ATF и e621/e926 появляется блок «Избранное аккаунта …» с кнопкой
  «Скачать избранное». Расширение листает избранное этого аккаунта прямо в браузере — страницы сайта по одной, с
  паузами, как их открыл бы человек (проверку сайта, Cloudflare, проходит человек на сайте — расширение её не обходит),
  и передаёт номера постов программе. Программа скачивает то, чего нет в библиотеке (с тегами сайта, блоклистом и
  «Большой загрузкой»; если какие-то посты она не берёт — скажет, сколько и почему), а потом
  прогоняет скачанное парсером по всем сайтам — теги других сайтов добавляются к карточкам. Ход — в «Скачать →
  Загрузки». В следующий раз на той же странице — «Докачать новые»: только то, что лайкнули после (на Danbooru, ATF и
  e621 листаются только новые страницы, на rule34.xxx и Gelbooru — всё избранное, но скачивается только новое). Сама
  программа новые лайки не проверяет. Нужна Local Booru 5.44.141. После обновления файлов расширения — кнопка
  «Обновить» (↻) у него на странице `chrome://extensions/`;
- **(0.10.1) пропуск через проверку Cloudflare — тоже в программу:** вместе с cookies сайта манги расширение передаёт
  строку браузера (User-Agent): пропуск Cloudflare (`cf_clearance`) годится только для того браузера, который его
  получил. Помогает там, где Cloudflare смотрит только на cookie и строку браузера; Nude-Moon смотрит на большее — его
  страницы и картинки программа берёт своим браузером окна (Local Booru 5.44.132), обновлять расширение ради него не
  нужно. Сайты Nude-Moon (nude-moon.org, .net, .fun) — в разрешениях расширения.
- **(0.10.0) вход на сайты манги — в программу само:** откройте сайт манги или манхвы, который знает программа
  (Remanga, MangaLib, HentaiLib, AllHentai, ReadManga и другие из «Настройки → Сайты манги»), и войдите — расширение
  передаст программе cookies этого сайта, а у MangaLib и HentaiLib и токен входа из хранилища сайта. Сменились
  cookies (вышли и вошли снова) — передаст новые; одинаковое дважды не шлёт. В «Сайтах манги» программы у каждого
  сайта «Открыть сайт» (вкладка откроется в этом браузере) и «Обновить вход» (расширение передаст вход сразу; для
  токена MangaLib, если его вкладка не открыта, на секунду откроет её в фоне). Только сайтам из списка программы;
  значения нигде не показываются. Сайт на новом адресе (его задали в программе) — «Ещё» → «Разрешить сайты манги»;
  выключить — «Вход на сайты манги — в программу». Нужна Local Booru 5.44.100. После обновления файлов расширения —
  кнопка «Обновить» (↻) у него на странице `chrome://extensions/`;
- **(0.9.1) теги со страницы — только теги поста:** слово поиска из ссылок сетки (`tags=…`, `tags=all`) и ссылки меню
  сайта тегами больше не считаются; категория тега (художник, персонаж, копирайт, мета) берётся из списка тегов
  страницы. Программа 5.44.10 и сама не даёт странице заменить теги, которые карточке дал сайт;
- **(0.9.0) манга на nhentai:** галереи, которые уже есть в папке манги программы, размываются с меткой «Уже есть»
  (щелчок по метке показывает обложку), а другие версии того же тайтла — другой язык, другая загрузка — с меткой
  «Есть: японский»; на странице галереи — строка над названием. В окне расширения: «Манга на nhentai, которая уже
  есть — размывать / скрывать / только метка / не отмечать» и «И другие её версии». Нужна Local Booru 5.44 с
  выбранной папкой манги;
- **(0.8.0) «Подписаться» в панели:** на странице поиска по тегам — блок «Поиск на сайте» с кнопкой «Подписаться»
  (подписка в программе на этот поиск этого сайта) или «Добавить этот сайт к подписке», если подписка на тот же
  поиск есть на другом сайте;
- **(0.8.0) блоклист программы на сайтах:** посты с тегами из блоклиста «Подписок» размываются (метка «Блоклист: …»
  показывает картинку) или скрываются — «Блоклист программы» в окне расширения; копия блоклиста работает и при
  закрытой программе;
- **(0.7.0) панель у правого края вместо плашки справа снизу:** маленький язычок «LB» (на нём — сколько карточек
  выбрано); панель выезжает при наведении, щелчок по язычку её закрепляет. В панели — сколько карточек страницы уже
  есть в библиотеке, сколько новых и апгрейдов, кнопки «Отправить выбранные», «Все новые», «Все апгрейды», «Всю
  страницу», «Снять выбор». В окне расширения: «Панель справа — не показывать» убирает её совсем;
- **(0.7.0) щелчок по метке «Уже есть»** открывает эту карточку в окне программы (окно выходит вперёд);
- новое окно расширения: состояние связи сверху, разделы «На сайтах», «Связь с программой», «Без программы», «Ещё»;
- контекстная команда «Скачать в Local Booru» без браузерной папки Downloads;
- pairing token + одноразовые task tokens;
- External Browser Resolver для Cloudflare, TinEye и Ascii2D;
- мультивыбор карточек и массовая отправка: Alt+клик по карточке — выбрать, Alt+Shift+клик — выбрать подряд
  (Ctrl/⌘+клик, как обычно, открывает пост в новой вкладке);
- каждая карточка описывается сама: свой пост, своя картинка; пост, который показывает страница, —
  отдельная карточка (метка «Уже есть», но страница не прячется); «Скачать в Local Booru» на миниатюре
  сетки или «похожих» берёт именно этот пост (0.6.1);
- бейджи exact/variant/upgrade/family partial;
- полноценные Pixiv multipage original и ugoira;
- declarative site profiles из Local Booru;
- явная передача cookies/User-Agent только текущего домена;
- event long-poll с watchdog вместо частого polling;
- **офлайн-режим (0.6):** расширение хранит у себя список того, что есть в библиотеке (MD5 картинок и
  удалённых файлов, номера постов booru), и когда Local Booru закрыта, прячет и помечает «Уже есть» по
  этому списку; «Скачать в Local Booru» при закрытой программе ставит пост в очередь (число на значке),
  очередь уходит в программу, как только она снова запущена. Список обновляется сам раз в 10 минут
  (полностью — раз в сутки) и кнопкой «Обновить офлайн-список и отправить очередь» в popup;
- одна управляемая служебная вкладка для browser bridge: Pixiv/resolver используют её последовательно, ошибки закрывают её, успешная фоновая работа переводит её на `about:blank` и закрывает через минуту простоя.

Расширение не получает путь к локальному архиву. При upload-resolver ему передаются только ограниченные байты временного reverse-файла. Cookies booru-сайтов передаются только после нажатия соответствующей кнопки; на Windows Local Booru хранит их через DPAPI. Cookies сайтов манги (0.10.0) — только сайтов из списка программы, сами; программа держит их в своей папке настроек и никуда не показывает.
