# Local Booru Companion 0.8.0 — Chrome / Edge / Brave / Chromium

## Установка

1. Запустите Local Booru v466 или новее.
2. Откройте `chrome://extensions/` или соответствующую страницу браузера.
3. Включите режим разработчика и загрузите папку `extensions/chrome_local_booru_companion` как распакованное расширение.
4. В Local Booru создайте одноразовый код сопряжения, затем введите его в popup.
5. Нажмите «Обновить профили сайтов». Для пользовательских сайтов отдельно выдайте optional permissions.

## Возможности

- **(0.8.0) «Подписаться» в панели:** на странице поиска по тегам — блок «Поиск на сайте» с кнопкой «Подписаться»
  (подписка в программе на этот поиск этого сайта) или «Добавить этот сайт к подписке», если подписка на тот же
  поиск есть на другом сайте;
- **(0.8.0) блоклист программы на сайтах:** посты с тегами из блоклиста «Подписок» размываются (метка «Блоклист: …»
  показывает картинку) или скрываются — «Блоклист программы» в окне расширения; копия блоклиста работает и при
  закрытой программе;
- **(0.7.0) панель у правого края вместо плашки справа снизу:** маленький язычок «LB» (на нём — сколько карточек
  выбрано); панель выезжает при наведении, щелчок по язычку её закрепляет. В панели — сколько карточек страницы уже
  есть в библиотеке, сколько новых и апгрейдов, кнопки «Отправить выбранные», «Все новые», «Все апгрейды», «Всю
  страницу», «Снять выбор». В окне расширения: «Панель справа — не показывать» убирает её совсем;
- **(0.7.0) щелчок по метке «Уже есть»** открывает эту карточку в окне программы (окно выходит вперёд);
- новое окно расширения: состояние связи сверху, разделы «На сайтах», «Связь с программой», «Без программы», «Ещё»;
- контекстная команда «Скачать в Local Booru» без браузерной папки Downloads;
- pairing token + одноразовые task tokens;
- External Browser Resolver для Cloudflare, TinEye и Ascii2D;
- мультивыбор карточек и массовая отправка: Alt+клик по карточке — выбрать, Alt+Shift+клик — выбрать подряд
  (Ctrl/⌘+клик, как обычно, открывает пост в новой вкладке);
- каждая карточка описывается сама: свой пост, своя картинка; пост, который показывает страница, —
  отдельная карточка (метка «Уже есть», но страница не прячется); «Скачать в Local Booru» на миниатюре
  сетки или «похожих» берёт именно этот пост (0.6.1);
- бейджи exact/variant/upgrade/family partial;
- полноценные Pixiv multipage original и ugoira;
- declarative site profiles из Local Booru;
- явная передача cookies/User-Agent только текущего домена;
- event long-poll с watchdog вместо частого polling;
- **офлайн-режим (0.6):** расширение хранит у себя список того, что есть в библиотеке (MD5 картинок и
  удалённых файлов, номера постов booru), и когда Local Booru закрыта, прячет и помечает «Уже есть» по
  этому списку; «Скачать в Local Booru» при закрытой программе ставит пост в очередь (число на значке),
  очередь уходит в программу, как только она снова запущена. Список обновляется сам раз в 10 минут
  (полностью — раз в сутки) и кнопкой «Обновить офлайн-список и отправить очередь» в popup;
- одна управляемая служебная вкладка для browser bridge: Pixiv/resolver используют её последовательно, ошибки закрывают её, успешная фоновая работа переводит её на `about:blank` и закрывает через минуту простоя.

Расширение не получает путь к локальному архиву. При upload-resolver ему передаются только ограниченные байты временного reverse-файла. Cookies передаются только после нажатия соответствующей кнопки; на Windows Local Booru хранит их через DPAPI.
