# Local Booru Companion 0.11.0 — Firefox

Функции совпадают с Chromium-версией: pairing/task tokens, browser resolver, batch import, Pixiv original/ugoira, профили сайтов, доменная передача cookies и quality/family badges. Все browser-bridge задачи сериализуются через одну управляемую служебную вкладку; обычные вкладки пользователя не перенаправляются.

0.11.0: «Скачать избранное» — лайки аккаунта в программу: на странице аккаунта (профиль или избранное) на rule34.xxx,
Gelbooru, Danbooru, ATF и e621/e926 — блок «Избранное аккаунта …» с кнопкой «Скачать избранное». Расширение листает
избранное в браузере (страницы сайта по одной, с паузами; проверку сайта проходит человек — расширение её не обходит) и
передаёт номера постов программе: она скачивает то, чего нет в библиотеке, и прогоняет скачанное парсером по всем
сайтам. Потом на той же странице — «Докачать новые». Нужна Local Booru 5.44.141. После обновления файлов —
about:debugging → «Этот Firefox» → «Перезагрузить» у расширения.

0.10.1: пропуск через проверку Cloudflare — тоже в программу: вместе с cookies сайта манги расширение передаёт строку
браузера (User-Agent) — пропуск Cloudflare (`cf_clearance`) годится только для браузера, который его получил. Помогает
там, где Cloudflare смотрит только на cookie и строку; Nude-Moon смотрит на большее — его страницы и картинки программа
берёт своим браузером окна (Local Booru 5.44.132). Сайты Nude-Moon — в разрешениях расширения.

0.10.0: вход на сайты манги — в программу само: откройте сайт манги или манхвы из «Настройки → Сайты манги» программы
и войдите — расширение передаст программе его cookies (у MangaLib и HentaiLib — и токен входа). «Открыть сайт» и
«Обновить вход» — в «Сайтах манги» программы. В Firefox разрешения на сайты выдаются отдельно: «Ещё» → «Разрешить
сайты манги» (или about:addons → расширение → «Разрешения»). Нужна Local Booru 5.44.100.

0.9.1: теги со страницы — только теги поста: слово поиска из ссылок сетки (`tags=…`, `tags=all`) и ссылки меню
сайта тегами больше не считаются; категория тега берётся из списка тегов страницы.

0.9.0: манга на nhentai — галереи, которые уже есть в папке манги программы, размываются с меткой «Уже есть», другие
версии того же тайтла (другой язык, другая загрузка) — с меткой «Есть: японский»; «Манга на nhentai, которая уже есть»
и «И другие её версии» в окне расширения. Нужна Local Booru 5.44.

0.8.0: «Подписаться» в панели на странице поиска по тегам (подписка в программе) и блоклист программы на сайтах —
такие посты размываются или скрываются («Блоклист программы» в окне расширения), и при закрытой программе тоже.

0.7.0: вместо плашки справа снизу — язычок «LB» у правого края, панель выезжает при наведении (в окне расширения её
можно выключить); щелчок по метке «Уже есть» открывает карточку в окне программы; новое окно расширения.

Офлайн-режим (0.6): когда Local Booru закрыта, карточки помечаются «Уже есть» по сохранённому в расширении списку библиотеки, а «Скачать в Local Booru» ставит пост в очередь, которая уходит в программу при её запуске.

## Временная установка

1. Запустите Local Booru v466 или новее.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Выберите «Загрузить временное дополнение» и укажите `manifest.json`.
4. Создайте одноразовый код в Local Booru и введите его в popup.

Для постоянной установки Firefox требует подписанный XPI. Путь локального архива расширению не передаётся.

Мультивыбор: Alt+клик по карточке — выбрать, Alt+Shift+клик — выбрать подряд (Ctrl/⌘+клик открывает пост в новой вкладке). С 0.6.1 каждая карточка описывается сама (свой пост, своя картинка), а «Скачать в Local Booru» на миниатюре берёт именно этот пост.
