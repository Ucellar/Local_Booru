# Локальная AI-модель NO_MATCH

NO_MATCH-классификация real/booru использует локальную CLIP-модель `openai/clip-vit-base-patch32`.

Варианты поставки:

1. FULL_AI-сборка: папка `models/clip` уже вложена в программу.
2. Маленькая сборка: при первом запуске программа сама скачивает модель в:

   `Local_Booru_Archive/settings/models/clip`

Это не API классификации: изображения пользователя не отправляются. Интернет нужен только один раз для загрузки публичных весов модели. После скачивания классификация работает локально.

Для exe-сборки, которая должна сама скачать и использовать CLIP, в окружение сборки должны быть установлены зависимости из `requirements_visual_ai.txt`:

```text
torch
transformers
safetensors
```

Если модель не скачалась, откройте вкладку `Брак` и нажмите `Скачать AI-модель` или `Что с AI?`.
