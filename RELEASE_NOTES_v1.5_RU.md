# Local Booru v1.5

Релиз про первый запуск, английскую публикацию и более безопасную пересборку SQLite-базы.

## Главное

- При первом запуске появляется выбор языка: **Русский** или **English**.
- Выбор сохраняется, поэтому окно больше не появляется для той же рабочей папки/профиля.
- Исправлен краш миграции `m024_reverse_branch_status` после удаления и пересоздания SQLite-базы.
- Legacy-импорт NO_MATCH и реестра удалённых файлов теперь идёт пачками, чтобы не держать SQLite заблокированной на минуты.
- Парсер больше не должен воспринимать заблокированную SQLite-базу как пустую.
- Добавлены более безопасные startup-проверки SQLite и low-memory профиль для больших архивов.
- Добавлен английский README для GitHub.

## Для существующих пользователей

Существующие настройки языка должны сохраниться. Окно выбора языка рассчитано на чистый профиль/новую рабочую папку.

Если база специально пересобирается с нуля, приложение нужно закрыть и удалить всю SQLite-тройку:

```text
local_booru_index.sqlite3
local_booru_index.sqlite3-wal
local_booru_index.sqlite3-shm
```

Медиа этим релизом не дублируются. Структура `Local_Booru_Archive/output` и `Local_Booru_Archive/settings` остаётся прежней.
