# FIX26 — Ideal Architecture Experiment

Цель этой ветки — не косметический фикс, а попытка приблизить Local Booru к архитектуре, которая выдерживает 100k–500k файлов.

## Главный принцип

UI больше не должен быть местом, где выполняются тяжёлые операции.

Нельзя делать в UI-потоке:

- rglob по огромному архиву;
- массовый подсчёт MD5;
- пересборку SQLite;
- чтение всех тегов;
- загрузку всех строк галереи;
- создание всех preview;
- массовое удаление;
- поиск дубликатов.

## Что изменено

### Галерея

Галерея больше не загружает весь список изображений из SQLite при открытии.

Теперь логика такая:

1. `scan_library()` читает только счётчики тегов/source.
2. Количество найденных файлов считается через `COUNT(*)`.
3. Текущая страница загружается через `LIMIT/OFFSET`.
4. Теги/source догружаются только для видимых карточек.

Это должно убрать зависания на 100k+ файлов.

### SQLite

Добавлены функции:

- `total_count()`;
- `count_search_items()`;
- `_where_for_search()`.

Поиск остаётся SQL-only:

- `tag1 tag2` = пересечение через SQL;
- `-tag3` = исключение через SQL;
- bucket/source тоже фильтруются в SQL.

### Индексация

Автоиндексация при открытии галереи остаётся выключенной.

Добавлена кнопка в настройках:

`Пересобрать SQLite-индекс в фоне`

Она запускает `index_library()` через общий `TaskManager`, а не в UI-потоке.

### Task Manager

`MainWindow` теперь создаёт общий:

`self.task_manager`

Через него нужно постепенно переводить:

- АПТ;
- АСП;
- дубликаты;
- удаление по тегу/source;
- thumbnail generation;
- cache cleanup.

## Что ещё не идеально

Эта ветка не является финальной.

Остались зоны риска:

- PostPage всё ещё получает контекст текущей страницы, а не полноценный SQL-cursor;
- random в SQL-режиме пока работает по текущей странице;
- удаление по тегу/source ещё можно дополнительно перевести в фоновую задачу;
- дубликаты пока не полностью SQL-first;
- thumbnail queue ещё не отдельный сервис.

## Следующий правильный этап

FIX27 должен сделать:

- `GallerySqlModel` на `QAbstractListModel`;
- полноценный SQL cursor для PostPage;
- thumbnail worker queue;
- duplicate scan через TaskManager;
- delete-by-tag/source через TaskManager;
- единый progress panel для всех задач.
