# FIX27 Full Rebuild Attempt

Эта ветка — не косметический патч, а попытка сделать проект ближе к нормальному локальному движку архива на 100k-500k файлов.

## Главная архитектура

```text
UI
  ↓ только команды и страницы
TaskManager
  ↓ фоновые задачи
Services
  ↓ бизнес-операции
SQLite Repository
  ↓ один источник правды
Файлы на диске + thumbnail cache
```

## Что считается источником правды

SQLite. Не `.txt`, не `.json`, не гигантский Python-кэш.

Sidecar-файлы больше не обязательны для нормальной работы. Если они где-то остались — это только наследие старых веток.

## Что нельзя делать в UI

- rglob по архиву
- MD5 для всех файлов
- чтение всех тегов
- создание всех превью
- фильтрация 500k объектов в Python
- удаление тысяч файлов без фоновой задачи

## Что добавлено

- `core/architecture.py` — общие лимиты и правила.
- `core/services/index_service.py` — потоковая индексация пачками.
- `core/services/library_service.py` — API галереи/удаления поверх SQLite.
- `core/database/repository.py` — SQL-поиск, пагинация, удаление.
- `core/database/maintenance.py` — optimize/stats.
- `core/task_manager.py` — единый менеджер фоновых задач.
- `docs/FIX27_FULL_REBUILD.md` — этот файл.

## Почему не переписано на Rust/Go прямо сейчас

Полный rewrite GUI + booru parsing + browser cookies + Qt/WebEngine на Rust/Go за один проход даст не приложение, а нерабочий скелет. Правильный путь:

1. стабилизировать Python GUI;
2. оставить SQLite как контракт данных;
3. вынести тяжёлые куски в отдельные CLI/библиотеки позже:
   - duplicate scan;
   - thumbnail generation;
   - bulk hashing;
   - index vacuum.

Python + PySide6 может нормально жить с 500k файлов, если не грузить 500k объектов в UI.

## Как проверять

1. Запуск.
2. Галерея.
3. Настройки → Пересобрать SQLite-индекс в фоне.
4. Галерея → поиск.
5. Настройки → Статистика SQLite.
6. Удаление по тегу/source.
7. Дубликаты.

## Главный принцип дальнейших фиксов

Если симптом: “зависло”, не чинить конкретную кнопку. Проверять слой:

- UI случайно делает тяжёлую работу?
- задача должна быть в TaskManager?
- операция идёт через services?
- запрос идёт через repository?
- нет ли per-file SQL/JSON в цикле?
