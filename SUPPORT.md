# Support

For bugs, crashes, and feature requests, use GitHub Issues.

When reporting a bug, include:

- Local Booru version;
- Windows version;
- Python version, if running from source;
- what you clicked or ran;
- the relevant log lines;
- whether the SQLite database was intentionally deleted or reset.

Do not attach private media, cookies, or a full personal SQLite database unless you are sure it is safe to share.
