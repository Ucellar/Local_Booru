# Security Policy

## Supported versions

Only the latest public release is expected to receive fixes.

## Reporting a vulnerability

Please open a GitHub issue with enough detail to reproduce the problem. If the report contains private paths, tokens, cookies, or archive metadata, remove that information before posting.

## Important notes

Local Booru is a local archive manager. It can interact with user-selected websites, local files, browser cookies, SQLite databases, and downloaded media. Do not run it on irreplaceable data without backups.

Never publish:

- browser cookies;
- local workspace files;
- SQLite databases from a private archive;
- downloaded media;
- logs containing private file paths if those paths matter to you.
